## Technical Highlights

### Format Choice: HTML/CSS
**Why HTML/CSS instead of traditional design files?**

1. **Precision:** Exact dimensional control (cm, inches)
2. **Accessibility:** Opens in any web browser, no special software needed
3. **Customization:** Easy text editing without design skills
4. **Print-Ready:** Built-in print functionality with proper media queries
5. **Version Control:** Text-based files, easy to track changes
6. **Professional Output:** Export to PDF for print shops

### Design Features
- Responsive scaling for screen preview
- Print-optimized layouts
- Google Fonts for professional typography
- Modern CSS (Flexbox, Grid)
- Cross-browser compatible
- High-resolution ready

### Color Palette
- **Primary Gradient:** #667eea (blue) → #764ba2 (purple)
- **Accent:** White with transparency for depth
- **Scratch Area:** Silver gradient (#c0c0c0 → #a0a0a0)
- **Text:** High contrast white on gradient, dark on white
