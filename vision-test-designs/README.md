# Eye & Vision Testing Product - Design Files

This project contains print-ready designs for an eye and vision testing product offering.

## Deliverables

### 1. Gift Card (13.1 cm x 10.1 cm)
- File: `gift-card.html`
- Dimensions: 13.1 cm x 10.1 cm (5.16" x 3.98")
- Features: Embedded scratch card area, product information, branding

### 2. Scratch Card (Credit Card Size)
- File: `scratch-card.html`
- Dimensions: 8.56 cm x 5.398 cm (3.375" x 2.125")
- Features: Brand name, URL, product code area

### 3. Marketing Poster (18" x 24")
- File: `poster.html`
- Dimensions: 18" x 24" (45.72 cm x 60.96 cm)
- Features: Product benefits, call-to-action, visual appeal

## How to Use

1. Open each HTML file in a web browser
2. Use browser's print function (Ctrl+P / Cmd+P)
3. Set print settings:
   - Remove headers and footers
   - Set margins to none
   - Enable background graphics
   - Choose appropriate paper size

## Customization

Each file contains clearly marked sections for:
- Brand name/logo
- Website URL
- Product codes
- Color schemes
- Marketing copy

## Print Specifications

- All designs use CMYK-friendly colors
- High contrast for readability
- Professional healthcare aesthetic
- Print-ready dimensions with bleed areas
